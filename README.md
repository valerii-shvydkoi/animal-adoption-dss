# 🐾 Adoptify

**Веб-орієнтована система підтримки прийняття рішень для адопції тварин в умовах кризових ситуацій.**

---

## 🚀 Швидкий старт

### 🔧 1. Запуск бекенду (Django + Docker)

```bash
cd backend
docker-compose up --build
```

---

### 💻 2. Запуск фронтенду (React + Vite)

```bash
cd frontend
npm install
npm run dev
```

---
