# Демо-сценарій захисту Adoptify

## Підготовка бази

```bash
docker compose exec backend python manage.py seed_demo --reset
```

Локально без Docker:

```bash
cd backend
python manage.py seed_demo --reset
```

Команда очищає дані застосунку, створює демонстраційні ролі, притулки, тварин, заявки, анкету AHP та локальні фото. Пароль для всіх демо-акаунтів: `AdoptifyDemo2026!`.

## Акаунти

- `admin@adoptify.demo` — адміністратор платформи, перевірка заявок на нові притулки та системної аналітики.
- `manager@adoptify.demo` — менеджер притулку, керування тваринами, командою і заявками волонтерів.
- `volunteer@adoptify.demo` — волонтер, перегляд підопічних і заявок на адопцію.
- `user@adoptify.demo` — користувач із пройденою анкетою AHP, рекомендаціями та обраними тваринами.
- `new.user@adoptify.demo` — користувач без анкети; у каталозі не бачить персональних відсотків сумісності.

## Послідовність показу на одному ноутбуці

1. Відкрити каталог як гість: показати фільтри, картки, обране без переходу на сторінку входу.
2. Увійти як `user@adoptify.demo`: показати, що обране гостя переноситься в акаунт, а каталог сортується за AHP-сумісністю.
3. Відкрити профіль і анкету: змінити ім'я або умови проживання, зберегти, перевірити миттєве оновлення меню.
4. Подати заявку на тварину, потім перейти в "Мої заявки" та показати статус.
5. Вийти й увійти як `manager@adoptify.demo`: додати тварину з фото з комп'ютера або URL, переглянути заявки волонтерів.
6. Увійти як `volunteer@adoptify.demo`: переглянути заявки на адопцію та змінити статус.
7. Увійти як `admin@adoptify.demo`: показати глобальну аналітику та заявку на верифікацію нового притулку.

## Що підкреслити в дипломі

- AHP не змушує користувача заповнювати складні матриці вручну: інтерфейс збирає пріоритети через прості порівняння і формує узгоджені ваги.
- Каталог не показує персональні рекомендації без результату анкети, тому немає хибної впевненості у підборі.
- Гостьове обране ізольоване від акаунтів і переноситься тільки після успішного входу.
- Ролі розділені: адміністратор верифікує платформу, менеджер керує притулком, волонтер обробляє адопцію.
