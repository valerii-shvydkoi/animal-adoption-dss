# Adoptify Frontend

Клієнтська частина дипломного застосунку Adoptify. Інтерфейс побудований як робоча система, а не landing page: перший екран відкриває каталог тварин, а ключові сценарії винесені в окремі кабінети за ролями.

## Основні сторінки

- `/` і `/catalog` — каталог з фільтрами, пагінацією, PWA-банером і картками тварин.
- `/questionnaire` — AHP-анкета з перевіркою узгодженості та запуском підбору.
- `/my-results` — збережені результати СППР.
- `/my-requests` — заявки користувача на адопцію.
- `/volunteer/*` — кабінет волонтера.
- `/shelter/*` — кабінет менеджера притулку.
- `/admin/*` — адміністративна аналітика, користувачі, притулки та логи.

## Запуск

```bash
npm install
npm run dev
```

За замовчуванням API викликається через `/api/v1/`; Vite прокидує `/api` і `/media` на Django backend.

## Перевірки

```bash
npm run lint
npm run build
```

## Production-збірка

Dockerfile збирає Vite-застосунок і віддає його через nginx. Nginx також прокидує `/api/` і `/media/` до backend-сервісу Docker Compose.
